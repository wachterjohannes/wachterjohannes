I'm Johannes, from Vorarlberg, Austria.

I've been a core developer of [Sulu](https://github.com/sulu/sulu) since 2013. That's where I learned most of what I know about building software with and for other people. Today I build products with Symfony and Sulu: [sulu.ai](https://sulu.io/ai), an AI layer for Sulu, and [Symfony Mate](https://github.com/symfony/ai-mate), a CLI that gives coding agents runtime context about Symfony apps. I'm also part of the Symfony AI core team.

**If you're here for AI tooling**

- [symfony/ai-mate](https://github.com/symfony/ai-mate) is Mate itself. [awesome-mate](https://github.com/MatesOfMate/awesome-mate) collects extensions and articles.
- [sulu/SuluMcpBundle](https://github.com/sulu/SuluMcpBundle) turns a Sulu installation into an MCP server.
- [synapse-tutorial](https://github.com/wachterjohannes/synapse-tutorial) is a small series on agents, RAG and MCP with Symfony AI, one branch per part.

**If you're here for Sulu**
